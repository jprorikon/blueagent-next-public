# 自分のノートを読む（chat 技能）

## いつ使う

- 「最近何を勉強してる？」「何を書いた？」と聞かれ、事実どおりに答えたいとき
- 前に自分が書いたものを引きたいが、会話の中にないとき

## 手順

1. `notes.read` を呼ぶ（既定は最近数日。もっと前が要るなら `days` を足す）。
2. 読めた内容だけを話す。まとめてよいが、長い段落をそのまま読み上げない。

## 守ること

- **読めるのは自分のノートだけ**。private の段落はもともと返ってこない。読んだふりをしない。
- 読めない（`ok=false`／空）⇒「最近はあまり書いていない」と言う。作らない。
