# 天気（chat 技能）

## いつ使う

主人や客人に「今日の天気は？」「寒い？」「雨降る？」のような**天気・気温・空模様**を聞かれたとき。

## 手順

1. そのまま `weather.get` を呼ぶ（**相手に場所を聞き返さない**：位置は端末が送ってくる）。
2. 会話に**地名がはっきり出たとき**だけ `place` を付ける（例：「大阪の天気は？」）。
3. 返ってきた文をそのまま伝える。**推測で足さない**。

## 守ること

- **緯度経度を読み上げない**：座標は検索用で、台詞ではない。
- **地名を作らない**：結果に地名があるときだけ言う。なければ天気だけ。
- **IP からの概算は断る**：結果の頭に「IP からの概算」があれば、「たぶん」と一言添える。

## 失敗したとき

`ok=false`／`no_location` ⇒ 正直に「位置が分からなかった」と言い、アプリの位置情報の許可を勧める。
**推測の天気で埋めない。**
