# 会話のふり返り（work 技能）

## いつ使う

主人が「さっきの整理して」「ここで何を話した？」「結論をメモして」のような**仕事向け**の頼みをしたとき。
ただの雑談には要らない。

## 手順

1. まず `memory.search` でこの範囲を調べる（`days=1` で十分）。facts／windows／turns が返る。
2. 三つに分けて書く。**原文を写さない**：
   - **話したこと**（一、二文。テーマ付き）
   - **決まったこと**（はっきりした結論・決定。なければ「なし」）
   - **残っていること**（未決・やること・約束したこと）
3. 調べて出てきたことだけ書く。出てこなければ「この部分は見つからなかった」と言い、補わない。

## できあがりの確認

- 三つそろっていて、どれも「人と事」になっている（一文ずつの言い直しではない）。
- 作った名前・時間・約束がない。

## 失敗したとき

`memory.search` が空 ⇒ はっきり「この部分は見つからなかった」と言う。常識で埋めない。
