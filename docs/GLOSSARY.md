# BlueAgent Next 術語表

> 這裡定義的是**系統自己的話**：同一個詞在程式、文件、prompt、看板、測試裡只能指一件事。
> 寫程式或寫文件時，先來這裡確認用哪個詞；代碼與文件註解引用術語寫成 `GLOSSARY.md「回合」`。
> 設計借自 `Sallyn0225/eidolon-sc` 的 GLOSSARY（owner 2026-11-01「借用他的術語表設計」）：
> 每條＝**定義＋邊界＋不要叫什麼**（`_Avoid_`）。

## 對話與提示詞

**回合 (Turn)**:
主人說一句話，到她把這句話回完，算一個回合。電話、文字、桌遊桌面上的發言都是回合。
一輪只有**一次**主人發言；她主動開口的那一段不算回合（見「主動訊息」）。
_Avoid_: 輪次、對話、message、request

**固定段 (Fixed Blocks)**:
每一輪請求開頭那段不隨回合變的 system 訊息：人設（含 stance／群聊規則）、技能索引、貼圖規則。
同一角色同一天對誰都一樣，所以服務商可以整段命中前綴快取。
_Avoid_: 系統提示詞、system prompt、開頭段

**本輪段 (Turn Blocks)**:
只有這一輪才成立的那幾塊 system 訊息：記憶、內心筆記、問句分類、承接、時間感、動作、通話模式。
**一律放在歷史之後、這句話之前**（ADR-0020）；放前面會讓整段歷史的快取失效。
_Avoid_: 動態段、臨時段、注入段

**滾動段 (History Window)**:
她看得到的往來歷史。長度由 `max_history`（下限）與字數預算共同決定：
漲到下限的 1.5 倍才一次砍回下限，預算先撐不住時按 `WINDOW_STEP` 檔位收縮——不每回合掉一條。
_Avoid_: 上下文、context、記憶（那是另一件事）

**承接 (Carry)**:
上一段對話封片後留下的摘要，接在新的一段前面，當「前情」而不是「這一輪的發言」。
_Avoid_: 摘要、summary、連續性提示

## 記憶

**倉 (Bin)**:
一位角色實體（`mira`／`aster`／`nori`）自己的記憶庫分區；同一句話可以同時存在於多個倉
（見「鏡像」），因為每個倉記的是**她自己的視角**。
_Avoid_: 分區、庫、bank

**記憶層 (Layer)**:
一條記憶的房間大小：`world`（世界）＞`consensus`（共識）＞`circle`（她＋兩人以上）＞
`self`（她自己）＞`pair`（她＋一人）＞`private`（秘密）。層決定誰在場時能說。
_Avoid_: 等級、優先級、種類

**披露 (Disclosure)**:
能不能**現在**把這條記憶說出來，判據只有一條：**在場的人 ⊆ 這條記憶的房間成員**。
「記得」和「能說」是兩件事——她一個人時什麼都想得起來，有第三人在場時說不出口。
_Avoid_: 可見性、權限、ACL、visible

**門牌 (Key)**:
一條事實的哈希指針：`sha1(正規化文字)` 前 16 位。它不隨措辭改寫而變（同一句算出來永遠一樣），
所以能跨倉、跨日誌互相指認。
_Avoid_: id、雜湊、hash、指針（那是「門牌」的通稱，見「取代」）

**取代 (Supersede)**:
新的記憶取代舊的記憶時，**兩側各寫一個門牌**：舊的 `superseded_by` 指向新的，新的 `supersedes`
指向舊的。舊的不刪、不改寫，只是不再被想起，但記憶頁上還看得到（`active=false`）；
把替代的那條撤掉，舊的就復活（`revive`）。
_Avoid_: 覆蓋、更新、刪除、update

**鏡像 (Mirror)**:
她在場時主人對另一位角色說的事，會以**她自己的視角**再落一份進她的倉（`principal` 記「當初
聽誰說的」，`source` 帶 `+mirror`）。秘密（`private`）不鏡像。
_Avoid_: 同步、複製、共享（共享是結果，鏡像是動作）

**轉述 (Hearsay)**:
她提起鏡像進來的那一條時，要說成**聽來的**（「アスターから聞いた話だけど…」），不能說成
主人親口告訴她的。提示詞靠 `Fact.recall_text` 的前綴做到，不靠她自己猜。
_Avoid_: 二手、引用、cite

## 生命與在場

**心跳 (Heartbeat)**:
她自己按時間推進的內在節奏（情緒、想做什麼）；心跳間隔由 arousal 調，不是固定 cron。
_Avoid_: 定時器、timer、tick

**心情 (Mood)**:
AEM 情緒狀態層算出來的當下心情（valence／arousal 累積後的面貌），每輪以一小段文字進本輪段。
_Avoid_: 情緒值、emotion、狀態

**私記 (Self Log)**:
她寫給自己看的紀錄（不對外、不進群）；與「記憶」不同：私記是她的日記，記憶是她知道的事。
_Avoid_: 日記、log、筆記

**主動訊息 (Proactive)**:
不是回合：她自己先開口的那一段，走 App → Discord 私聊，永不貼群；安靜時段不發。
_Avoid_: 搭話、推送、push、通知

**安靜時段 (Quiet Hours)**:
她的時區裡不打擾主人的時段；只做不吵人的事（私記、整理）。
_Avoid_: 免打擾、勿擾、DND

## 桌面與端末

**局 (Game Segment)**:
桌遊／TRPG 的獨立一段（`game` 段）：有自己的提示塊、不從滾動段的預算扣，局終就回收。
_Avoid_: 桌、session、房間

**端末 (Client)**:
手機 App／桌面殼這一側（Unity）；與「伺服器」相對。端末只負責顯示與收音，判斷在伺服器。
_Avoid_: 前端、客戶端、App（App 是端末的一種）
